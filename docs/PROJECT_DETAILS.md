# Tadpole - Interactive Story Engine

**Build stories. Shape choices. Create worlds.**

**GitHub:** https://github.com/fardinkamal62/tadpole-interactive-story-engine

---

## Overview

A web-based visual novel engine that enables non-programmers to design and publish branching, choice-driven interactive stories through a graphical interface.

## Motivation

Visual novel and interactive story games rely heavily on branching narratives, player choices and state-based progression. While many powerful game engines exist, most require programming knowledge or complex scripting, which creates a barrier for writers, artists, and hobbyists who want to focus purely on storytelling.

Our motivation is to build a lightweight, web-based interactive story engine that allows users to create visual novel-style games without writing code. By providing a visual editor, structured scene management and a rule-based choice system, Tadpole aims to democratize interactive storytelling and make game creation accessible to a wider audience.

From an academic perspective, this project also provides an opportunity to apply core software engineering principles such as system design, data modeling, graph-based structures, and modular architecture while building a real-world usable system.

---

## Features

### Core Features
- User authentication and profile management
- Attribute system (e.g., relationship level, trust, courage)
- Conditional choices and endings based on attribute values
- Save and load game progress

### Creator Tools
- Drag-and-drop scene creation
- Visual editor to create scenes with background images and dialogue
- Graph-style visualization of story flow
- Choice creation for each scene
- Branching story flow by linking choices to other scenes

---

## Importance of Features
- **Visual Editor:** Enables non-programmers to create content easily, fulfilling the core goal of accessibility.
- **Branching Story System:** Allows complex narratives and multiple endings, which is essential for visual novels.
- **Attribute System:** Adds depth and consequences to player choices, increasing engagement.
- **Conditional Logic:** Ensures meaningful decision-making and dynamic storytelling.
- **Save/Load System:** Enhances usability for players and supports longer narratives.

Together, these features transform Tadpole from a simple story viewer into a full interactive storytelling engine.
